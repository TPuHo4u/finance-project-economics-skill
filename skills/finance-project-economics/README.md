# ФЭО и экономика проектов

Навык `finance-project-economics` для Codex и Claude Code, собранный по материалам курса «Финансы и экономика» СберМиниМБА.

Помогает выбрать показатель проекта, подготовить ФЭО, сравнить варианты инвестиций, рассчитать NPV/IRR/ROI/окупаемость и проверить фактический финансовый эффект. Отдельно разбирает автоматизацию и AI: время, FTE, реализацию экономии и полную стоимость владения. Это рабочий навык; к экзамену он не готовит.

Работает самостоятельно и как продолжение `ux-research-coach` и других навыков курса. Принимает готовые исследование, CJM, карточку проблемы или варианты решения без повторного ввода. Добавляет финансовую оценку и возвращает критерии следующей проверки, сохраняя статусы фактов и гипотез. Другие навыки для запуска не обязательны. [Как устроена передача результата](references/collaboration.md).

## Примеры запросов

- «Используй finance-project-economics. Проект сокращает время обработки заявки. Помоги выбрать показатель, который мы действительно можем улучшить, и способ подтвердить эффект».
- «Подготовь ФЭО по этим данным и сравни доработку старой системы с покупкой новой. Неизвестные параметры вынеси отдельно».
- «Проверь финансовую модель AI-проекта: в ней часы умножили на зарплату и назвали экономией».
- «Разбери план-факт: выручка выросла, прибыль снизилась, денег на расчётном счёте не хватает. Что проверить и какие данные нужны?».
- «Продолжи работу ux-research-coach по этому CJM: выбери показатель, свяжи проблему с экономикой и подготовь критерии пилота. Сохрани неподтверждённые гипотезы».

## Установка из архива

Распакуйте `finance-project-economics.zip` в постоянное место. Папка `finance-project-economics` должна содержать [SKILL.md](SKILL.md), `references/` и `templates/`. Сохраняйте их вместе. В командах ниже замените `/полный/путь/finance-project-economics` реальным путём к распакованной папке.

Для Codex:

```sh
mkdir -p ~/.agents/skills
ln -s "/полный/путь/finance-project-economics" ~/.agents/skills/finance-project-economics
```

Для Claude Code:

```sh
mkdir -p ~/.claude/skills
ln -s "/полный/путь/finance-project-economics" ~/.claude/skills/finance-project-economics
```

Команды не перезаписывают существующий навык. Если имя уже занято, сначала проверьте существующую установку. Начните новый чат или обновите список навыков клиента, затем явно вызовите `finance-project-economics`. Наличие файлов на диске отдельно от фактического появления в каталоге клиента.
